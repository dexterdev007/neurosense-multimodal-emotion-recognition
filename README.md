# 🧠 NeuroSense — Multimodal Human Emotion Recognition System

> A full-stack AI system that detects human emotion by fusing five independent biological and behavioral signals: **EEG**, **MEG**, **MRI**, **Speech**, and **Facial Expression** — powered by trained SVM models and a **late-fusion meta-classifier**.

## 📚 Step-by-Step Model Training Guide

### Prerequisites

1. **Activate your virtual environment:**
   ```bash
   cd "human emotion recognition system"
   source venv/bin/activate
   pip install -r NeuroSense/webdev/backend/requirements.txt
   pip install matplotlib seaborn jupyter
   ```

2. **Download datasets** into `NeuroSense/datasets/`:

| Modality | Dataset | Download From | Place In |
|----------|---------|---------------|----------|
| EEG | DEAP emotions.csv | [Kaggle: EEG Emotion Dataset](https://www.kaggle.com/datasets/birdy654/eeg-brainwave-dataset-feeling-emotions) | `datasets/eeg/eeg/emotions.csv` |
| MEG | Auto-generated | Notebook creates it automatically | `datasets/meg/meg_features.csv` |
| MRI | Brain Tumor MRI | [Kaggle: Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) | `datasets/mri/archive/Training/` and `datasets/mri/archive/Testing/` |
| Speech | TESS | [Kaggle: TESS Dataset](https://www.kaggle.com/datasets/ejlok1/toronto-emotional-speech-set-tess) | `datasets/speech/` (emotion-named subfolders) |
| Face | FER2013 | [Kaggle: FER2013](https://www.kaggle.com/datasets/msambare/fer2013) | `datasets/face/fer2013/fer2013.csv` |

### Training Order (MUST follow this sequence)

```bash
cd NeuroSense/notebooks
jupyter notebook
```

Run each notebook **top to bottom** in this order:

| # | Notebook | What It Does | Output .pkl Files | Time |
|---|----------|-------------|-------------------|------|
| 1 | `01_EEG_Emotion_Recognition.ipynb` | Loads EEG CSV → StandardScaler → SVM(RBF) | `eeg_model.pkl`, `eeg_scaler.pkl`, `eeg_label_encoder.pkl` | ~30 sec |
| 2 | `02_MEG_Emotion_Recognition.ipynb` | Generates synthetic MEG data → SVM | `meg_model.pkl`, `meg_scaler.pkl`, `meg_label_encoder.pkl` | ~15 sec |
| 3 | `03_MRI_Brain_Tumor.ipynb` | Loads 7K images → PCA(150) → SVM | `mri_model.pkl`, `mri_scaler.pkl`, `mri_pca.pkl`, `mri_label_encoder.pkl` | ~5 min |
| 4 | `04_Speech_Emotion_Recognition.ipynb` | Extracts 162 librosa features → SVM | `speech_model.pkl`, `speech_scaler.pkl`, `speech_label_encoder.pkl` | ~3 min |
| 5 | `05_Face_Emotion_Recognition.ipynb` | Loads FER2013 → PCA(100) → SVM | `face_model.pkl`, `face_scaler.pkl`, `face_pca.pkl`, `face_label_encoder.pkl` | ~8 min |
| 6 | `06_Fusion_Pipeline.ipynb` | Stacks probs from all models → LogReg | `fusion_model.pkl`, `fusion_label_encoder.pkl` | ~20 sec |

> ⚠️ **Notebook 06 requires notebooks 01–05 to be run first** — it loads the EEG artifacts to generate training data for the fusion layer.

### After Training — Restart the Backend

```bash
cd ../webdev/backend
# Kill existing server if running, then:
uvicorn app:app --host 127.0.0.1 --port 8000 --reload
```

The server will print:
```
[NeuroSense] Loading artifacts from: /path/to/artifacts
  Loaded: eeg/eeg_model.pkl
  Loaded: eeg/eeg_scaler.pkl
  ...
[NeuroSense] All artifacts loaded successfully.
```

## ✅ How to Know Models Are Trained Correctly

### 1. Check Notebook Output

Every notebook prints accuracy after training. Look for these numbers:

| Notebook | Expected Accuracy | If You See < This, Something's Wrong |
|----------|-------------------|--------------------------------------|
| 01 EEG | 75–85% | < 50% |
| 02 MEG | 70–80% (synthetic) | < 40% |
| 03 MRI | 90–97% | < 70% |
| 04 Speech | 80–90% | < 60% |
| 05 Face | 65–80% | < 45% |
| 06 Fusion | 85–92% | < 70% |

### 2. Verify Artifact Files Exist

After running all notebooks, you should have **19 .pkl files**:
```bash
find NeuroSense/artifacts -name "*.pkl" | wc -l
# Should output: 19
```

### 3. Each Notebook Has a "Verify" Cell

The last cell in each notebook loads the saved model and predicts on 3 test samples:
```
Sample 1: POSITIVE (84.2% confidence)
Sample 2: NEGATIVE (76.1% confidence)
Sample 3: NEUTRAL (69.8% confidence)
```

If the labels make sense and confidence is > 60%, the model is working.

### 4. Test via the API

After restarting the server, test directly:
```bash
# EEG test (32 features)
curl -X POST http://localhost:8000/api/eeg/predict \
  -H "Content-Type: application/json" \
  -d '{"features": [0.5, -0.3, 0.8, 0.1, -0.6, 0.4, 0.2, -0.9, 0.7, 0.3, -0.2, 0.5, 0.1, -0.4, 0.6, 0.8, -0.1, 0.3, 0.5, -0.7, 0.2, 0.4, -0.3, 0.6, 0.1, -0.5, 0.8, 0.3, -0.2, 0.7, 0.4, -0.6]}'
```

You should get back a response like:
```json
{
  "modality": "EEG",
  "prediction": "POSITIVE",
  "confidence": 0.7823,
  "probabilities": {"NEGATIVE": 0.1, "NEUTRAL": 0.12, "POSITIVE": 0.78}
}
```

### 5. Test via the UI

Open `http://localhost:8000`, click **Random Example** on EEG/MEG cards, then click **Fused Prediction**. You should see a prediction with confidence > 60%.

## 🧬 Modalities Deep Dive

### 1. 🧠 EEG — Electroencephalography
| Property | Value |
|---|---|
| **Signal** | 32 electrodes on scalp → electrical brain activity |
| **Dataset** | DEAP — 32 subjects, 8,064 samples, 32 channels |
| **Features** | 32 numeric frequency-band power values |
| **Key Marker** | Alpha asymmetry (left vs. right frontal lobe) |
| **Model** | SVM (RBF, C=10) |
| **Classes** | POSITIVE / NEGATIVE / NEUTRAL |
| **Accuracy** | ~78% |

### 2. 🔮 MEG — Magnetoencephalography
| Property | Value |
|---|---|
| **Signal** | Magnetic fields from neural currents (unaffected by skull) |
| **Dataset** | Synthetically generated following DECAF schema |
| **Features** | 50 frequency-band power values |
| **Model** | SVM (RBF, C=10) |
| **Classes** | POSITIVE / NEGATIVE / NEUTRAL |
| **Accuracy** | ~75% |

### 3. 🏥 MRI — Magnetic Resonance Imaging
| Property | Value |
|---|---|
| **Signal** | Brain tumor classification from grayscale scans |
| **Dataset** | Kaggle Brain Tumor MRI — 7,023 images |
| **Pipeline** | Upload → Grayscale 64×64 → Flatten → Scaler → PCA(150) → SVM |
| **Classes** | glioma / meningioma / pituitary / no_tumor |
| **Accuracy** | ~96% |

### 4. 🎤 Speech — Audio Emotion Recognition
| Property | Value |
|---|---|
| **Signal** | 162 acoustic features from voice recordings |
| **Dataset** | TESS (~2,800 .wav files, 7 emotions) |
| **Features** | 80 MFCC + 24 Chroma + 30 Mel + 7 Contrast + 6 Tonnetz + 3 ZCR/RMS/Rolloff + 12 padding |
| **Model** | SVM (RBF, C=10) |
| **Accuracy** | ~86% |

### 5. 😐 Face — Facial Expression Recognition
| Property | Value |
|---|---|
| **Signal** | Pixel-level emotion from face images |
| **Dataset** | FER2013 — 35,887 images (48×48 grayscale) |
| **Pipeline** | Upload → 48×48 → Flatten/255 + 4 stats → Scaler → PCA(100) → SVM |
| **Classes** | POSITIVE / NEGATIVE / NEUTRAL |
| **Accuracy** | ~72–80% |

### 6. 🔗 Fusion — Late Fusion Meta-Classifier
| Property | Value |
|---|---|
| **Method** | Stacks probability vectors from all active modalities |
| **Algorithm** | Logistic Regression |
| **Input** | Up to 15 probabilities (3 per modality × 5) |
| **Why LR?** | Probability space is nearly linear; LR is fast and interpretable |
| **Accuracy** | ~89.7% |

## 🤖 CNN vs SVM Discussion

### Current Approach: SVM + PCA

All modalities use **SVM with RBF kernel** (Support Vector Machine). For image modalities (MRI, Face), PCA reduces dimensionality first.

| Modality | Current (SVM + PCA) | With CNN (ResNet18) |
|----------|---------------------|---------------------|
| MRI | 85–96% | 95–98% |
| Face | 72–80% | 88–94% |
| Speech | 80–88% | 90–95% (mel spectrogram as image) |

### What CNN Would Give You

A **CNN (Convolutional Neural Network)** learns spatial patterns directly from raw images by sliding filters across pixels. For MRI and Face, a pretrained ResNet18 would:
- Learn hierarchical features (edges → textures → shapes → objects) automatically
- Remove the need for manual PCA dimensionality reduction
- Achieve significantly higher accuracy on image tasks

### Should You Add CNN?

**Recommended approach: Keep SVM as primary, add CNN as comparison in the same notebook.**

This is the best strategy because:

1. **Shows breadth of knowledge** — you explored multiple approaches
2. **SVM is easier to explain in viva** — hyperplanes, kernels, margins are well-understood
3. **CNN comparison demonstrates you know the state-of-the-art**
4. **Both models can coexist** — train CNN, save as `.pth`, compare accuracy side by side

### Practical Impact on Deployment

| Factor | SVM (.pkl) | CNN (.pth) |
|--------|-----------|-----------|
| **Model file size** | 1–50 MB | 50–200 MB |
| **Dependencies** | scikit-learn only | + PyTorch (~2GB) or TensorFlow |
| **Inference speed** | <5ms per prediction | 10–50ms per prediction |
| **GPU required?** | No | For training yes, inference can be CPU |
| **Backend changes** | None | Need to add `torch` loading + inference code |
| **Deployment size** | ~500MB total | ~2.5GB total |

### Can You Use Multiple Models in One Notebook?

**Yes!** The notebooks already compare SVM vs Random Forest vs Logistic Regression. You can add CNN in the same notebook:
