Theory

Everything you need to understand the science behind each modality and the ML pipeline.

What is Emotion Recognition?

Emotion recognition is the automatic detection of a person's emotional state using biological and behavioural signals. Machines today are emotionally blind — a hospital monitor tracks pulse but cannot detect fear. NeuroSense closes this gap by reading three independent signals simultaneously.

Why Multimodal?

Every single signal has a blind spot. EEG fails from motion artefacts. Face recognition fails when expressions are suppressed. Speech fails when someone is silent. These failures are independent — combining three signals means their weaknesses cancel out. If each modality has 25% error rate, all three agreeing wrongly is just 1.5%.

Valence-Arousal Model

All emotions sit on a 2D graph. Valence is the positive-negative axis — happiness is high valence, sadness is low. Arousal is the energy axis — anger is high arousal, calm is low. Your system maps this to three classes: POSITIVE (high valence), NEGATIVE (low valence), NEUTRAL (middle).

What is EEG?

Electroencephalography places 32 metal electrodes on the scalp to detect tiny electrical pulses from groups of neurons firing together. EEG cannot be faked — brain activity is involuntary. Dataset: DEAP — 32 subjects, 8,064 samples, 32 channels. Model: SVM RBF. Accuracy: 78%.

Five Frequency Bands

  • Delta (0.5–4 Hz) — Deep sleep, severe distress
  • Theta (4–8 Hz) — Sadness, memory, depression
  • Alpha (8–13 Hz) — KEY emotion marker — valence asymmetry
  • Beta (13–30 Hz) — Anxiety, stress, active thinking
  • Gamma (30+ Hz) — Emotional intensity and salience

Alpha Asymmetry — The Key Marker

Less left frontal alpha = more left brain activity = POSITIVE emotion. More left frontal alpha = less activity = NEGATIVE emotion. This left-right difference cannot be voluntarily suppressed — making it the single most reliable non-invasive emotion marker in neuroscience.

EEG Pipeline

DEAP CSV → StandardScaler → SVM RBF → 3 Classes

Input: 32 numeric features. Output: POSITIVE / NEGATIVE / NEUTRAL with confidence score.

How Voice Carries Emotion

Angry speech is fast, loud, and high-pitched. Sad speech is slow, quiet, and monotone. These differences are captured by 162 acoustic features extracted by librosa. Speech is the most naturally available modality — people speak all day in ways that EEG monitoring cannot replicate.

Facial Expression Recognition

The human face has 43 muscles. Paul Ekman established that 6 basic expressions — happiness, sadness, anger, fear, disgust, surprise — are universal across all cultures, suggesting a biological basis. Your model learns pixel-level patterns from FER2013: 35,887 labelled 48×48 greyscale face images. Accuracy: 91%.

Why PCA for Face?

48×48 pixels = 2,304 values + 4 statistical features (mean, std, p25, p75) = 2,308 total features. Too many for SVM. PCA reduces to 100 components capturing 90%+ variance. This enables fast and accurate classification without overfitting to pixel noise.

Face Pipeline

Upload Image → 48×48 / 255 → 2308 features → Scaler + PCA 100 → 3 Classes

Dataset: FER2013 — 35,887 images. Accuracy: 91%.

What is Late Fusion?

Each modality model predicts independently and outputs a probability vector. These vectors are stacked together and fed to a meta-classifier. Late fusion = combining at the output stage. This keeps each modality in its own world with its own appropriate preprocessing and model — only combining the final probabilities.

How It Works — Step by Step

EEG model → [0.80, 0.12, 0.08]
Speech model → [0.65, 0.25, 0.10]
Face model → [0.70, 0.20, 0.10]
Stack → 9-number vector
Logistic Regression → POSITIVE 89.7%

Why Logistic Regression for Fusion?

By the time data reaches fusion, it is already clean probability numbers from three trained models. The 9-number probability space already has a nearly linear decision boundary. Logistic Regression is fast, interpretable, and perfect here. A complex model would overfit on the limited fusion training data.

Why Fusion Wins

If each modality has 25% error rate and errors are independent, all three agreeing wrongly = 0.25³ = 1.5%. Fusion accuracy is 6–11% higher than any single modality. EEG alone: 78%. Fusion: 89.7%. The improvement comes from modalities compensating for each other's weaknesses.

SVM — Support Vector Machine

Finds the hyperplane that separates emotion classes with the maximum possible margin. The RBF kernel maps data to higher dimensions where non-linear boundaries become linear. C=10 enforces strict boundary. probability=True enables Platt scaling to output confidence scores needed for fusion.

kernel='rbf' C=10 gamma='scale' probability=True

PCA — Principal Component Analysis

Reduces many features to fewer dimensions while preserving maximum variance. For Face: reduces 2,308 features to fewer principal components. PCA must be saved as .pkl and applied identically at inference, using the same transformation as training.

StandardScaler

Subtracts mean and divides by standard deviation for each feature. SVM is extremely sensitive to feature magnitude — without scaling, large-value features dominate small-value features. Must be fitted on training data only, then applied to both training and new inputs using the same learned statistics.

Training vs Inference

Training (notebooks): Run once on your laptop. Learns patterns from thousands of labelled examples. Saves result as .pkl files.

Inference (backend): Every time a user predicts. Loads .pkl files. Applies what was already learned to one new sample. Model never retrains from user input.

What is a .pkl File?

A serialised Python object saved to disk by joblib.dump(). Contains every learned parameter of the trained model — support vectors, weights, decision boundary, scaler means and standard deviations, PCA components. joblib.load() reads it back identically. The backend loads all 19 .pkl files once at startup and reuses them for every prediction.
